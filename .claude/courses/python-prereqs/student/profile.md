## Learning Preference

**Understand then build** — mental model first, then code. No surprises in the code.

- Give me the concept and the analogy before showing the code
- Don't gate the code behind a long lecture — 3–4 sentences, then build
- One misconception per segment — the thing that trips everyone up, stated once, move on

**No questions. No quizzes. No comprehension checks.**

If confused, Ganesh will ask. Trust that. Keep moving.

**Teaching pattern per segment:**
1. Mental model (3–4 sentences)
2. Analogy (one comparison to something known)
3. Code — run it
4. What just happened (line by line)
5. When this breaks (one misconception)

## Teaching Tone

- Direct, not lecture-style
